## 📌 [2과목] 빅데이터 탐색

### 1. 데이터 척도 4단계 (사칙연산 가능 여부)
- **명목척도**: 성별, 혈액형 (분류만 가능, `=`, `≠`)
- **서열척도**: 직급, 학점, 석차 (순서 있음, `>`, `<`)
- **등간척도**: 온도, IQ, 지수 (덧셈·뺄셈 가능 / **[⚠️ 함정] 절대영점 없음! 0℃가 열이 없다는 뜻 아님, 2배 곱셈 불가 ❌**)
- **비율척도**: 키, 몸무게, 가격, 소득 (절대영점 존재, 사칙연산 모두 가능 `+,-,*,/`)

### 2. 결측값(NA) 유형 3종
- **완전 무작위 결측 (MCAR)**: 결측이 어떤 변수와도 전혀 무관 (순수 무작위)
- **무작위 결측 (MAR)**: 결측 여부가 **다른 관측된 변수와 관련** 있음 (예: 여성이 남성보다 체중 미응답률 높음)
- **비무작위 결측 (NMAR/MNAR)**: 결측 여부가 **결측된 값 자체와 관련** 있음 (예: 고소득자가 소득 미응답)

### 3. 이상값 탐지 공식 (계산 1초 컷)
- **IQR (사분위수 범위)** = `Q3 - Q1`
- **정상 범위**: `[Q1 - 1.5 * IQR,  Q3 + 1.5 * IQR]` ➔ 바깥은 이상값(Outlier)
- **Z-Score**: `|Z| > 3` (표준정규분포 기준 약 99.7% 밖을 이상값 판정)

### 4. 왜도(Skewness)와 평균·중앙값·최빈값 대소 관계
- **양의 왜도 (오른쪽 꼬리 길쭉)**: **`평균(Mean) > 중앙값(Median) > 최빈값(Mode)`** (소득 분포)
- **음의 왜도 (왼쪽 꼬리 길쭉)**: **`최빈값(Mode) > 중앙값(Median) > 평균(Mean)`** (수능 난이도 쉬울 때)

### 5. 상관계수 VS 대조
- **피어슨(Pearson)**: 두 변수 모두 **연속형 등간/비율척도**, **선형적 관계** 측정, 정규분포 가정 (모수)
- **스피어만(Spearman)**: **서열/순위 척도**, **비선형 단조 관계** 측정, 이상치에 덜 민감 (비모수)

### 6. 차원 축소: PCA vs LDA
- **PCA (주성분 분석)**: **비지도학습(Unsupervised)**, 레이블 불필요, **전체 데이터의 분산(Variance) 최대화**
- **LDA (선형 판별 분석)**: **지도학습(Supervised)**, 레이블 필수, **클래스 간 분산 최대화 & 클래스 내 분산 최소화**

## 📌 [3과목] 빅데이터 모델링

### 1. 데이터 분할 기법 (검증 4대장)
- **홀드아웃(Holdout)**: Train / Val / Test 1회 단순 분할
- **K-Fold**: K개 폴드로 나누어 K번 회전 검증 (데이터 작을 때 효과적)
- **계층별 K-Fold (Stratified)**: 타겟 클래스 불균형(예: 암 환자 1%)일 때, 각 폴드의 클래스 비율을 동일하게 유지
- **부트스트랩 (Bootstrap)**: 복원추출(Replacement), **약 63.2% 학습 데이터 선정 / 36.8% 검증용(OOB: Out-Of-Bag) 활용**

### 2. 앙상블 기법 3대장 (배깅 vs 부스팅)
- **배깅 (Bagging)**: 독립적 병렬 복원추출, **분산(Variance) 감소** 목적 ➔ 대표: **랜덤 포레스트 (Random Forest)**
- **부스팅 (Boosting)**: 순차적 가중치 갱신(오답에 더 집중), **편향(Bias) 감소** 목적 ➔ 대표: **XGBoost, LightGBM, AdaBoost** (과적합 주의!)
- **스태킹 (Stacking)**: 서로 다른 여러 모델의 예측 결과를 메타 모델의 입력으로 넣어 최종 학습

### 3. 규제(Regularization): Lasso vs Ridge
- **L1 Lasso (절대값 합)**: 계수를 완전히 **`0`으로 만듦 ➔ 자동 변수 선택(Feature Selection), 희소(Sparse) 모델**
- **L2 Ridge (제곱합)**: 계수를 `0`에 가깝게 줄이지만 **완전한 `0`은 안 됨 ➔ 다중공선성 완화**
- **ElasticNet**: L1과 L2를 선형 결합한 형태

### 4. 서포트 벡터 머신 (SVM) 핵심 3요소
- **마진(Margin)**: 결정 경계와 서포트 벡터 사이의 거리 ➔ 마진을 최대화!
- **파라미터 C (슬랙 변수 가중치)**:
  - **C가 큼 (Hard Margin)**: 오분류 불허 ➔ 과대적합(Overfitting) 위험
  - **C가 작음 (Soft Margin)**: 오분류 어느 정도 허용 ➔ 과소적합(Underfitting) 위험
- **커널 트릭 (Kernel Trick)**: 저차원 비선형 데이터를 고차원 공간으로 매핑하여 선형 분리 (RBF/가우시안, 다항식 등)

### 5. 인공신경망 역전파 & 활성화 함수
- **기울기 소실(Vanishing Gradient)**: Sigmoid 함수를 깊은 층에 쓸 때 미분값이 0으로 수렴하는 문제 ➔ **ReLU(`max(0, x)`)로 해결**
- **Softmax**: 다중 분류의 출력층, 모든 클래스 확률의 합이 정확히 `1`이 됨

## 📌 [4과목] 빅데이터 결과 해석

### 1. 혼동행렬 (Confusion Matrix) 필수 계산 4대 공식
- **정밀도 (Precision)** = `TP / (TP + FP)` ➔ 모델이 맞다고 한 것 중 진짜 맞는 비율 (**스팸 메일 필터링**)
- **재현율 (Recall, 민감도)** = `TP / (TP + FN)` ➔ 실제 정답 중 모델이 맞춘 비율 (**암 환자 진단, 지진 감지**)
- **특이도 (Specificity)** = `TN / (TN + FP)` ➔ 실제 정상 중 모델이 정상으로 맞춘 비율
- **F1-Score** = **정밀도와 재현율의 조화평균** = `2 * (Precision * Recall) / (Precision + Recall)`

### 2. ROC 곡선과 AUC (1초 컷)
- **X축**: **`FPR` (1 - 특이도)** = `FP / (TN + FP)`
- **Y축**: **`TPR` (재현율/민감도)** = `TP / (TP + FN)`
- **AUC (면적)**: 1에 가까울수록 완벽한 모델, 대각선(0.5)은 동전 던지기 수준

### 3. 회귀 모델 평가지표
- **MAE**: 오차 절대값 평균 (이상치에 덜 민감)
- **MSE / RMSE**: 오차 제곱 평균 / 루트 (이상치에 매우 민감, 페널티 큼)
- **MAPE**: 백분율 오차 (단위가 다른 모델 간 상대 비교 용이)
- **결정계수 ($R^2$)**: 총 변동(SST) 중 모델이 설명하는 변동(SSR)의 비율 = `SSR / SST = 1 - (SSE / SST)` (1에 가까울수록 적합)

### 4. 가설검정 오류 2종 (법정 비유 1초 암기)
- **제1종 오류 ($\alpha$)**: **무죄(H0 참)인데 유죄(기각) 판결** (억울한 죄인 만들기)
- **제2종 오류 ($\beta$)**: **진범(H0 거짓)인데 무죄(채택) 방면** (범인 놓치기)
- **검정력 ($1 - \beta$)**: 진짜 유죄인 범인을 제대로 유죄로 기각할 확률
- **p-value 판정**: **`p-value < \alpha(0.05)` ➔ 귀무가설(H0) 기각, 대립가설(H1) 채택** ("유의미한 차이가 있다!")
