### 1. 네트워크프로토콜(TCP/IP) - ★★★ (총 10문항, 3회 모두 출제)

**핵심 포인트**
- lsof(List Open Files): 시스템에서 현재 열려 있는 파일/포트/소켓 목록을 출력하는 휘발성 데이터 수집 명령어(디스크 삭제와 무관).
- OSI 7계층-TCP/IP 매핑: IP는 네트워크 계층(L3, 비연결형), TCP는 전송 계층(L4, 신뢰성/흐름제어 담당) - 계층을 반대로 매칭하기 쉬움.
- WAF(웹 애플리케이션 방화벽): 애플리케이션 계층(L7)에서 SQL Injection, XSS 등 웹 공격을 탐지·차단.
- PAT(Port Address Translation): 공인 IP 1개와 포트 번호 조합으로 다수의 내부 호스트가 동시에 외부와 통신하도록 매핑하는 기술(단순 1:1 NAT보다 세분화).
- hosts 파일: DNS 서버 질의보다 먼저 로컬에서 조회되는 도메인-IP 매핑 파일로, 조작 시 파밍(Pharming) 공격에 악용 가능.
- ARP 테이블(ARP 캐시): IP-MAC 매핑 정보를 저장하는 로컬 메모리 테이블(`arp -a`로 확인).
- DHCP: IP 주소, 서브넷마스크, 게이트웨이를 자동 할당하는 프로토콜.

**회차별 출제 형식**
- 1회: lsof, OSI/TCP-IP 계층 매핑, WAF, PAT, hosts 파일 등 각 프로토콜/도구의 정의 위주.
- 2회: 전송 계층(TCP/UDP) 역할, hosts 파일 위조를 이용한 피싱 공격 문제.
- 3회: 데이터링크 계층(MAC), ARP 테이블, DHCP 등 심화 응용 문제.

**오답 함정/헷갈리는 개념**
- IP(L3, 네트워크 계층)와 TCP(L4, 전송 계층)의 역할과 계층을 뒤바꾸는 함정.
- NAT(1:1 주소 변환)와 PAT(포트 조합 다대일 변환)의 차이.

### 2. 이메일/웹아티팩트 - ★★ (총 4문항, 3회 모두 출제)

**핵심 포인트**
- WebCacheV01.dat: Windows 8/IE10 이후 도입된 ESE(Extensible Storage Engine) 기반 웹 캐시/방문이력 DB로, 구버전 index.dat를 대체.
- Chrome 등 크로미움 계열 브라우저는 방문 기록, 쿠키, 다운로드 정보를 SQLite DB 파일로 저장.
- 시크릿 모드(Incognito)는 로컬 파일시스템 DB에 흔적을 남기지 않고 메모리 세션으로만 동작하다 종료 시 소멸(단, 메모리 덤프 시점에는 흔적이 임시로 남을 수 있음).
- 쿠키(Cookie): 로그인 세션 유지를 위해 웹 서버가 클라이언트에 저장하도록 전송하는 식별용 변수 파일.

**회차별 출제 형식**
- 1회: index.dat와 WebCacheV01.dat 비교 문제.
- 2회: Chrome 브라우저 히스토리 저장 DB 엔진(SQLite) 문제.
- 3회: 시크릿 모드 아티팩트 저장 여부, 쿠키의 역할 문제.

**오답 함정/헷갈리는 개념**
- 시크릿 모드도 "메모리 덤프" 시점에는 흔적이 남을 수 있다는 예외 조건을 놓치기 쉬움.

### 3. 패킷분석 - ★ (총 3문항, 2·3회 출제)

**핵심 포인트**
- hosts 파일 위조를 이용한 피싱/파밍 공격 탐지 문제(네트워크프로토콜 파트와 연동).
- ARP 테이블(ARP 캐시)을 이용한 IP-MAC 매핑 확인(네트워크프로토콜 파트와 연동).
- pcap/pcapng: Wireshark 등 네트워크 분석 소프트웨어의 표준 패킷 덤프 포맷(libpcap 기반).

**회차별 출제 형식**
- 2회: hosts 파일 위조 탐지 문제.
- 3회: ARP 테이블, pcap/pcapng 확장자 문제.

**오답 함정/헷갈리는 개념**
- 별도 함정 언급 없음(다른 개념 문항과 중복 태깅된 재출제 위주).
