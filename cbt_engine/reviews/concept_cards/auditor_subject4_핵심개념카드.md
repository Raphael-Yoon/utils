### 핵심 포인트 요약
- **SDN (Software Defined Networking) 3개 평면과 2개 인터페이스 (2025년 기출)**:
  - `구조적 3개 평면`:
    - `Application Plane`: 최상위 네트워크 모니터링, 보안, QoS 관리 응용 프로그램 (SW).
    - `Control Plane`: 중앙 집중형 SDN 컨트롤러. 망 전체의 최적 경로 계산 및 정책 수립 (SW, x86 리눅스 서버 등에서 독립 구동).
    - `Data Plane`: 패킷을 실제로 포워딩(전송)하는 물리 스위치/라우터 하드웨어 (HW).
  - `2대 핵심 인터페이스`:
    - `Northbound Interface`: Application Plane ↔ Control Plane (RESTful API / JSON 활용).
    - `Southbound Interface`: Control Plane ↔ Data Plane (공식 명칭: **Control Data Plane Interface, CDPI** / 표준 통신 프로토콜: **OpenFlow**).
  - `트래픽 흐름 원칙`: **실제 사용자 데이터 패킷(유튜브, 웹 트래픽)은 컨트롤러로 올라가지 않고 Data Plane 스위치들끼리 초고속 하드웨어 링크로 직접 전달됨!** Southbound는 오직 제어 규칙(Flow Table)과 모니터링 신호만 오고 감.
- **차분 맨체스터(Differential Manchester) 파형 판독 공식 (2025년 기출)**:
  - 비트 주기 한가운데(Center)의 전이는 클록 동기화용이므로 무시하고, **비트와 비트 사이의 '경계선(Boundary)' 전이 유무**만 관찰.
  - 비트 경계선에 **신호 전이(수직선) 발생** ➔ **`0`**
  - 비트 경계선에 **신호 전이 없음 (수평 평탄선 유지)** ➔ **`1`**
- **VLAN 프레임 태깅 표준 IEEE 802.1Q ('닷원큐') (2025년 기출)**:
  - 복수 스위치 간 트렁크(Trunk) 링크에서 이더넷 프레임의 MAC과 Type 사이에 **4바이트(32비트) 크기의 VLAN 태그** 삽입 (TPID 2B + TCI 2B, 12비트 VID로 최대 4,094개 VLAN 지원). 8바이트 왜곡 주의.
- **통신 QoS 4대 핵심 지표 (2025년 기출)**:
  - `지터(Jitter)`: 패킷 교환망에서 네트워크 혼잡 등으로 인해 발생하는 **'패킷 간 지연 시간의 불규칙한 변이/편차'**. 실시간 음성(VoIP) 및 스트리밍 품질의 결정적 지표.
  - `지연(Latency)`, `패킷 손실(Packet Loss)`, `처리율(Throughput)`.
- **전자우편 프로토콜 명령어 (POP3 vs SMTP) (2025년 기출)**:
  - `POP3 (수신, 포트 110)`: `LIST` (목록 조회), `RETR` (메일 가져오기), `DELE` (삭제), `STAT` (통계).
  - `SMTP (발송, 포트 25)`: `HELO/EHLO`, `MAIL FROM`, `RCPT TO`, `DATA`.
- **전파 신호 파장 계산 공식 (2025년 기출)**:
  - $\lambda = \frac{v}{f}$ (전파 속도 $v = 3 \times 10^8$ m/s, $f = 3$ kHz = $3 \times 10^3$ Hz ➔ $\lambda = 100,000$ m).
- **오류 제어 vs 데이터 부호화 (2025년 기출)**:
  - 패리티(Parity), 블록합(LRC/Checksum), CRC는 전송 오류 검출 기법.
  - BCD(Binary Coded Decimal)는 10진수 숫자를 4비트 2진수로 표현하는 데이터 부호화 방식 (오류 검출 아님).
- **TCP 혼잡 제어 4단계**:
  - `Slow Start`: 개별 ACK마다 cwnd +1 (RTT마다 2배 지수 증가).
  - `Congestion Avoidance`: 임계값 도달 후 RTT당 1씩 선형 증가.
  - `Fast Retransmit`: 3 중복 ACK 감지 시 단 1개의 손실 패킷 즉시 재전송.
  - `Fast Recovery`: cwnd를 절반 지점(ssthresh)부터 1씩 완만하게 증가.
- **IPv4 vs IPv6 헤더 구조 비교**:
  - `기본 헤더`: IPv4는 가변(20~60B), IPv6는 **40바이트 고정**.
  - `IPv6 변경 사항`: **Header Checksum 삭제**, **IHL 삭제**, IPv4 `TTL` ➔ IPv6 **`Hop Limit`**으로 공식 개명.

- **IP 서브넷팅 마스터 4단계 황금 알고리즘 (2023년 기출 코칭 노트)**:
  - 1단계 [호스트 비트 산출]: $32 - \text{Prefix} = H$ (예: $32 - 28 = 4$비트).
  - 2단계 [블록 크기 산출]: $2^H$ ($2^4 = 16$).
  - 3단계 [블록 배수 나열]: $0, 16, 32, 48, 64 \dots$ (16의 배수 구간).
  - 4단계 [대표 주소 매핑]: 주어진 IP의 마지막 옥텟(예: .36)이 속한 구간(32~47)의 **맨 앞 시작 번호가 곧 해당 서브넷의 네트워크 대표 주소** ($\rightarrow$ `.32`).
  - `/24`의 경우 $32-24=8$비트, 블록 크기 256, 네트워크 대표 주소는 `.0`.
- **멀티캐스트 2대 진영 (IGMP vs 멀티캐스트 라우팅 프로토콜) (2023년 기출)**:
  - `호스트 ↔ 로컬 라우터 (출석체크/순수 제어 평면)`: **IGMP (Internet Group Management Protocol)** ➔ IPTV 시청자 가입/탈퇴/유지 상태 관리.
  - `전국 라우터 간 (배달 지도/트리 구축)`: **멀티캐스트 라우팅 프로토콜**
    - `DVMRP`: 최초의 거리벡터 기반, Flooding & Prune (무작정 브로드캐스팅 후 안 받는 곳 가지치기).
    - `CBT`: 코어 라우터 중심의 단일 양방향 공유 트리.
    - `PIM`: 유니캐스트 라우팅 프로토콜과 독립 동작 (PIM-DM, PIM-SM).
- **PPP(Point-to-Point Protocol) 보안 인증 대결 (PAP vs CHAP) (2023년 기출)**:
  - `PAP (Password Authentication Protocol)`: 2-Way 핸드셰이크, ID와 비밀번호를 **평문(Plaintext)으로 전송** ➔ 스니핑/도청에 극히 취약.
  - `CHAP (Challenge-Handshake Authentication Protocol)`: 3-Way 핸드셰이크, 서버가 난수(Challenge)를 보내면 클라이언트는 비밀번호를 결합한 **MD5 해시값만 회신** ➔ 비밀번호가 선로에 일체 노출되지 않아 안전함.
- **BGP4 (Border Gateway Protocol v4) 4대 메시지 (2023년 기출)**:
  - 자치시스템(AS) 간 라우팅 프로토콜(EGP), **TCP 179번 포트** 신뢰성 세션 사용.
  - `OPEN`: 피어 간 세션 수립.
  - `UPDATE`: 신규 경로 공지 및 도달 불가능 경로 철회 (가장 빈번한 교환 메시지).
  - `KEEPALIVE`: 주기적 생존 확인 (통상 60초).
  - `NOTIFICATION`: 에러 감지 시 통보 후 **즉시 세션 강제 종료**.
- **TCP/IP 전송 계층 포트 번호(Port Number) 체계 및 실무 (2023년 기출 코칭 노트)**:
  - `본질적 역할`: 전 세계 호스트를 찾는 IP 주소(Host-to-Host)와 달리, **동일 IP(호스트) 내에서 실행 중인 특정 애플리케이션 프로세스(소켓)를 식별 (Process-to-Process Delivery)**.
  - `크기`: **16비트 ($0 \sim 65,535$)**. (32비트 왜곡 주의!)
  - `3대 대역 구분`:
    - `Well-known (0 ~ 1,023)`: 네이버, 구글 등 **서버 데몬 표준 서비스 (★ 주어 주의)**. HTTP 80, HTTPS 443, SSH 22, DNS 53. 리눅스 root 권한 필수.
    - `Registered (1,024 ~ 49,151)`: 벤더/응용프로그램 등록용 (MySQL 3306, Oracle 1521, Tomcat 8080, Flask 5000, Django 8000).
    - `Dynamic / Private (49,152 ~ 65,535)`: **일반 사용자 클라이언트 (★)**가 웹서핑 시 OS로부터 임시로 부여받는 에페머럴 포트.
  - `독립 공존 원칙`: OS는 소켓을 `{프로토콜, IP, 포트}` 튜플로 식별하므로, **TCP와 UDP는 서로 다른 엔진으로서 동일한 포트 번호(예: DNS 53번)를 각각 독립적으로 중복 사용 가능**!
  - `실무 웹 포트의 원리`: 80번은 브라우저에서 생략 가능한 기본값(Default)일 뿐이며, 단일 서버에서 여러 웹 프로세스(cbt, k-sox, trade, infosd)를 띄울 때는 5000, 5001, 8000 등으로 포트를 분리하여 공존시킴. 가장 중요한 대표 서비스 1개는 언제든 80번 단독 사용 가능.
- **3계층 보조 프로토콜 4형제 (2023년 기출)**:
  - `ARP`: IP 주소(3계층) ➔ MAC 주소(2계층).
  - `RARP`: MAC 주소(2계층) ➔ IP 주소(3계층).
  - `ICMP`: IP 패킷 전송 오류 보고 및 네트워크 진단 (`ping`).
  - `IGMP`: 멀티캐스트 그룹 멤버십 관리.
- **네트워크 전송 방식 3대 패밀리와 IPv6 혁신 (2023년 기출)**:
  - `L2 이더넷 MAC / L3 IPv4`: 유니캐스트(1:1), 멀티캐스트(1:N), 브로드캐스트(1:All).
  - `L3 IPv6`: 유니캐스트, 멀티캐스트, **애니캐스트(1:Nearest 가장 가까운 1개 노드)** ➔ **브로드캐스트 전면 폐지**!
  - *(※ 2계층 MAC 하드웨어 주소 체계에는 애니캐스트가 존재하지 않음)*
- **소켓 프로그래밍 API (TCP 연결형 vs UDP 비연결형) (2023년 기출)**:
  - `TCP (SOCK_STREAM)`: `socket()` ➔ `bind()` ➔ `listen()` ➔ `accept()` ➔ **`recv()` / `read()`**, **`send()` / `write()`**.
  - `UDP (SOCK_DGRAM)`: `socket()` ➔ `bind()` ➔ **`recvfrom()`**, **`sendto()`** (상대방 주소 매회 명시).
  - *(※ 웹 프레임워크(Flask, Django)는 7계층 HTTP 위에서 동작하므로, 하부의 TCP 소켓 생성과 3-Way Handshake를 자동 추상화/은닉함)*
- **CRC 에러 검출 다항식 최고차항 $N$과 생성 비트열 크기 ($N+1$ 비트 공식) (2023년 기출)**:
  - 최고차항이 $x^{16}$인 생성다항식($x^{16} + x^{12} + x^5 + 1$)은 16차항부터 상수항($+1 = x^0$)까지 항이 총 17개 존재하므로 **생성 비트열 길이는 $N+1 = 17$비트**! (`1 0001 0000 0010 0001`).

---


- **동적 라우팅 프로토콜 거리 벡터(RIP) vs 링크 상태(OSPF) 길찾기 철학 (2022년 기출 코칭 노트)**:
  - `거리 벡터 (RIP)`: 벨만-포드 알고리즘 기반. 이웃 라우터와만 30초마다 전체 테이블 교환. 단순 거치는 라우터 수(홉 수, Hop Count) 기준. **최대 15홉 제한** (16홉은 도달 불가능/사망 판정으로 패킷 즉시 폐기 및 ICMP Destination Unreachable 통지).
  - `링크 상태 (OSPF)`: 다익스트라(SPF) 알고리즘 기반. 망 전체 라우터가 동일한 전체 토폴로지 맵(LSDB)을 구축하여 최단 경로 계산. 대역폭/지연시간 기준 메트릭, 홉 수 제한 없음. 대규모 망 적합.
- **전송 계층 UDP 헤더 8바이트 구조 및 체크섬 필드 (2022년 기출)**:
  - UDP 헤더는 8바이트 고정: 출발지 포트(2B) + 목적지 포트(2B) + 길이(2B) + **체크섬(2B)**.
  - 단순 비연결·비신뢰성 전송이지만, 데이터 무결성 검증을 위한 **체크섬 필드가 반드시 존재**함 (IPv4에서는 선택적 0 처리 허용, IPv6에서는 필수 적용). "체크섬 필드가 전혀 없다"는 단골 오답.
- **DHCP IP 자동 할당 4단계 절차 (D-O-R-A) (2022년 기출)**:
  - 1단계 `Discover`: 클라이언트가 브로드캐스트로 DHCP 서버 탐색 (서버 포트 UDP 67, 클라이언트 포트 UDP 68).
  - 2단계 `Offer`: 서버들이 임대 가능한 가용 IP 제안.
  - 3단계 `Request`: 클라이언트가 특정 서버의 제안을 채택하여 브로드캐스트로 확정 요청 (타 서버에 거절 통지 효과).
  - 4단계 `ACK`: 서버가 최종 임대 승인 및 IP 사용 확정 회신.

### 핵심 포인트 요약
- **시스템 진단 및 백도어 탐지 명령어 `netstat` (2025년 기출)**:
  - 어원: **Net**work **Stat**istics (네트워크 종합 통계 및 상태).
  - 핵심 옵션 해체:
    - `-a` (All): 연결된 세션뿐만 아니라 **대기(Listening) 중인 모든 포트** 출력 (백도어 대기 포트 탐지 필수).
    - `-n` (Numeric): 도메인/서비스명 역방향 조회 없이 **숫자 IP 및 포트 번호**로 직관적·고속 표시.
    - ➔ **`netstat -an`**: 침해사고 시 백도어 오픈 포트 및 외부 C&C 서버 연결 상태를 확인하는 표준 명령어.
    - `-r` (Routing): 라우팅 테이블 출력.
    - `-s` (Statistics): IP/TCP/UDP 프로토콜별 누적 통계 패킷 수 요약.
    - `-p`: Linux에서는 프로세스(PID/프로그램명), Windows에서는 프로토콜(TCP/UDP 필터링). *(Windows PID 확인은 `-ano`)*.
- **CPU 스케줄링 다단계 피드백 큐 (MLFQ) (2025년 기출)**:
  - 다단계 큐(MLQ)는 큐 간 프로세스 이동이 불가하여 하위 큐의 기아(Starvation) 발생.
  - 다단계 피드백 큐(MLFQ)는 **큐 간 동적 이동(피드백)을 완벽 허용** (CPU 집중 프로세스는 하위 큐 강등, 대기 시간 긴 프로세스는 에이징(Aging)을 통해 상위 큐로 승격하여 기아 방지).
- **가상 메모리 페이지 교체 알고리즘 (LRU vs LFU) (2025년 기출)**:
  - `LRU (Least Recently Used)`: **가장 오랫동안 사용되지 않은 시간(시간적 경과)**을 기준으로 교체.
  - `LFU (Least Frequently Used)`: 과거에 참조된 **횟수(빈도, Frequency)**가 가장 적은 페이지를 교체.
- **가상 머신(VM) vs 컨테이너(Docker) 완벽 비교**:
  - `가상 머신 (VM)`: 하이퍼바이저 필수, 게스트 OS(커널) 독립 탑재, 수십 GB 무거움, 완벽한 격리.
  - `컨테이너 (Docker)`: 호스트 OS 커널 공유, 하이퍼바이저 불필요, 초경량 초고속.

---


- **하이퍼바이저 2대 가상화 기법 (전가상화 vs 반가상화) (2023년 기출)**:
  - `전가상화 (Full-Virtualization, 완벽한 사기극)`:
    - 게스트 OS 소스코드 수정 전혀 없음.
    - 하이퍼바이저가 하드웨어 전체를 완벽히 에뮬레이션하므로 게스트 OS는 자신이 실제 물리 머신에서 도는 줄 알고 특권 명령을 직접 날림.
    - 하이퍼바이저가 특권 명령을 일일이 가로채서(Trap & Emulate) 번역하므로 **속도가 느리고 오버헤드가 큼**.
  - `반가상화 (Para-Virtualization, 솔직한 협력)`:
    - **게스트 OS 커널 소스코드 수정 필수**!
    - 게스트 OS가 자신이 가상화 환경임을 스스로 인지하고, 특권 명령을 하드웨어에 직접 던지지 않고 하이퍼바이저 전용 API인 **하이퍼콜(Hypercall)**을 직접 호출.
    - 에뮬레이션 오버헤드가 제거되어 **성능이 매우 뛰어남** (대표 제품: **Xen, 젠서버**).
- **유닉스 파일 시스템과 inode(Index Node) 관리 구조 (2023년 기출)**:
  - `디스크 4대 구역`: 부트 블록 ➔ 슈퍼 블록 (파일시스템 메타데이터 총괄) ➔ inode 테이블 (파일별 메타데이터) ➔ 데이터 블록 (실제 데이터).
  - `inode에 저장되지 않는 2대 핵심 요소 (단골 함정)`:
    - ① **파일 이름**: 디렉터리 파일 내부의 `(파일명 - inode 번호)` 매핑 테이블에 보관됨!
    - ② **소유자 문자열 이름**: inode에는 오직 숫자 형태의 사용자 식별자(**UID**)와 그룹 식별자(**GID**)만 저장됨!

- **서버 가상화 3단계 경량화 다이어트 아키텍처 (2022년 기출 코칭 노트)**:
  - `Type 2 (호스티드, 가장 무거움)`: Host OS 위에 가상화 앱(VMware Workstation, VirtualBox) 실행 후 게스트 OS 구동. Host OS 개입으로 I/O 오버헤드 큼.
  - `Type 1 (베어메탈, 표준 준수)`: Host OS 없이 물리 하드웨어 위에 하이퍼바이저(VMware ESXi, Xen, KVM) 직접 직결. 오버헤드 최소화, 엔터프라이즈 데이터센터 표준.
  - `컨테이너 (도커, 극도의 경량화)`: 게스트 OS를 완전히 버리고 Host OS의 리눅스 커널(네임스페이스/cgroups)을 공유. 초고속 기동 및 최소 자원 점유.
- **고가용성(HA) 이중화 및 장애 격리 메커니즘 (2022년 기출)**:
  - `Active-Active`: 모든 노드가 상시 동시 처리(부하 분산), 1대 장애 시 나머지 노드가 즉시 감당.
  - `Active-Standby`: Hot(전원 ON, 실시간 동기화, 수초 내 절체) vs Warm(전원 ON, 서비스 미가동, 수분 내 절체) vs Cold(전원 OFF, 수동 복구, 수십분 소요).
  - `SPOF (단일 장애점) 제거`: 어느 한 부품 고장으로 전체가 죽는 취약점 박멸이 HA의 근본 목적.
  - `Heartbeat (심장 박동)`: 노드 간 상호 상태 감시 필수.
- **교착상태(Deadlock) 4대 조건과 은행원 알고리즘 회피 (2022년 기출)**:
  - `4대 필요조건`: 상호배제, 점유대기, **비선점(No Preemption - 선점 아님!)**, 환형대기.
  - `은행원 알고리즘 (회피, Avoidance)`: 프로세스의 최대 자원 요구량을 사전에 파악하여, 자원 할당 후에도 시스템이 '안전 상태(Safe State)'를 유지할 수 있을 때만 할당을 승인하는 심사역(은행원) 메커니즘.
- **CPU 스케줄링 기아 현상 해결: 에이징(Aging) vs 타임 퀀텀 (2022년 기출)**:
  - 우선순위/SJF의 저우선순위 무한 대기(기아 현상) 해결책은 대기 시간에 비례해 우선순위를 점진적으로 승격시키는 **'에이징(Aging)'** 기법임.
  - 라운드로빈의 시간 할당량(Time Quantum)을 줄인다고 기아 현상이 완전히 해결되지 않으며, 너무 작게 하면 문맥 교환(Context Switching) 오버헤드 급증으로 시스템 성능이 파탄남.
- **가상 메모리 분할 기법의 물리적 대칭성 (2022년 기출)**:
  - `페이징 (고정 크기)`: 외부 단편화 없음, **내부 단편화 발생** (마지막 페이지 자투리).
  - `세그멘테이션 (가변 크기/논리 단위)`: 내부 단편화 없음, **외부 단편화 발생**.

### 5개년 출제 현황

### 핵심 포인트 요약
- **TTA 하드웨어 규모산정 지침 연계부하 보정비율 (2025년 기출)**:
  - `WEB 서버`: 연계부하 보정 = **0%** (연계 트래픽 직접 처리 안 함).
  - `WAS 서버 (단순 조회)`: 연계부하 보정 = **10%**.
  - `WAS 서버 (복합/갱신)`: 연계부하 보정 = **30%**.
- **성능공학 복합 업무 최대 TPS 산정 공식 (2025년 기출)**:
  - 복합 트랜잭션 1건의 가중평균 서비스시간 $ST = \sum (\text{업무별 비중} \times \text{처리시간})$.
  - $\text{최대 } TPS = \frac{\text{동시 처리 용량(동시 사용자/쓰레드 수)}}{ST}$.
- **스토리지 RAID 1+0 (RAID 10) 아키텍처 (2025년 기출)**:
  - 드라이브들을 먼저 2개씩 1:1 미러링(RAID 1)한 후, 그 세트들을 데이터 스트라이핑(RAID 0)으로 결합.
  - **패리티(Parity) 연산은 일절 사용하지 않음** (패리티는 RAID 3, 4, 5, 6 전유물).
  - 미러링 세트 내 1개 디스크 장애 시에도 무중단 서비스 지원.
- **디지털 논리회로 카르노맵(K-Map) 간소화 (2025년 기출)**:
  - 진리표에서 출력이 1인 최소항들을 $2^n$ 단위(2개, 4개, 8개)로 인접 칸끼리 최대한 크게 묶어 변수를 소거 ($F = A' + BC$).
- **플린(Flynn)의 컴퓨터 분류 체계 (2025년 기출)**:
  - `SIMD (Single Instruction Multiple Data)`: 단일 제어장치 명령으로 다수의 연산장치(ALU)가 대규모 벡터/배열 데이터를 병렬 연산 (현대 GPU 및 벡터 프로세서 핵심 구조).
- **캐시 메모리 평균 접근 시간 (AMAT) 공식 (2025년 기출)**:
  - $AMAT = \text{L1 접근시간} + (\text{L1 미스율} \times \text{L1 미스 패널티})$.
- **CRC LFSR(선형 피드백 시프트 레지스터) 회로도 판독 (2025년 기출)**:
  - 플립플롭 레지스터 단수 $N$개 ➔ 최고차항 $x^N$.
  - 데이터 유입 입력단 ➔ 상수항 $+1$.
  - 중간 피드백 경로의 XOR 게이트 위치 ➔ 해당 차수 $+x^k$ (예: 4단 레지스터 + 2단 뒤 XOR ➔ $x^4 + x^2 + 1$).
- **멀티미디어 데이터 압축 원리 (2025년 기출)**:
  - 데이터 내부의 반복 패턴 및 중복성(Redundancy)이 많을수록 불필요한 데이터를 제거할 여지가 크므로 **압축률이 높아짐**.
- **부동소수점 나눗셈 연산 (IEEE 754) (2025년 기출)**:
  - 가수는 나눗셈, **지수는 뺄셈** 수행. **지수 덧셈은 오직 곱셈의 전유물**이므로 나눗셈에는 불필요.
- **I/O 시스템 4단계 라이프사이클 및 '3개 묶음 패밀리' 출제 공식 (2024년 기출 코칭 노트)**:
  - `I/O 4단계 전담 분업 체계`:
    - 1단계 `주소 지정 (Addressing)`: 격리형 I/O(Isolated, 전용 IN/OUT 명령어) vs 메모리 맵 I/O(Memory-mapped, RAM 주소 통합, 일반 MOV 사용).
    - 2단계 `준비 확인 (Readiness)`: 소프트웨어 폴링(Polling, Busy Waiting 낭비) vs 인터럽트 구동(Interrupt, 비동기 신호 효율).
    - 3단계 `경합 중재 (Priority)`: 폴링(S/W) vs 데이지 체인(Daisy-chain, 직렬 H/W, 전파 지연) vs 병렬 우선순위 인코더(Parallel Priority Encoder, APIC 칩, 초고속).
    - 4단계 `데이터 전송 (Transfer)`: 프로그램 I/O(CPU 100% 혹사) ➔ 인터럽트 I/O(워드 단위) ➔ **DMA(CPU 개입 배제, 블록 단위 직통, 사이클 스틸링/버스트 모드)** ➔ 채널 I/O(I/O 전용 미니 CPU 구동).
  - `💡 [매니저님 착안] '3대 패밀리 + 이질적 1개' 범주 오류 출제 공식`:
    - 출제위원은 3단계 경합 중재의 3대 패밀리(Software polling, Daisy-chain, 병렬 우선순위 인코더)를 모아놓고, 4단계 데이터 전송인 **DMA**를 쓱 끼워 넣어 *"다음 중 I/O 우선순위 판별 메커니즘이 아닌 것은?"*과 같은 전형적인 범주 혼동 킬러 문항을 출제함. "3개가 한 묶음이 되는 곳은 무조건 4지선다 출제 표적"이라는 수험 법칙 정립.

- **리틀 엔디언(Little-Endian) 16진수 바이트 슬라이싱 공식 (2023년 기출)**:
  - 32비트 = 4바이트 = 16진수 8글자 ($16^8 = 2^{32}$).
  - 최하위 바이트(LSB)부터 0번지 메모리에 순차 저장하므로 **뒤에서부터 2글자(1바이트)씩 슬라이싱**:
    - `0x12345678` ➔ 0번지:`78`, 1번지:`56`, 2번지:`34`, 3번지:`12`.
  - 글자 수가 홀수 개(예: `0x1234567`)일 때는 맨 앞에 `0`을 패딩하여 짝수화(`0x01234567`) 후 뒤에서부터 2글자씩 분할 (`67`, `45`, `23`, `01`).
  - x86/ARM 인텔/스마트폰 CPU 연산 및 포렌식(NTFS/FAT)은 리틀 엔디언, 인터넷 통신(TCP/IP)은 빅 엔디언 표준.
- **ASCII 코드 '0'~'9' 4비트 직결 루틴 (8-4-2-1) (2023년 기출)**:
  - `'0'` = `0x30` = `0011 0000`, `'9'` = `0x39` = `0011 1001`.
  - 10진수 우회 없이 8-4-2-1 비트 조합(9 = $8+1 \rightarrow 1001$)으로 1초 만에 직결 산출.
- **스토리지 RAID 4 vs RAID 5 비교 (2023년 기출)**:
  - `RAID 4`: 단일 전용 패리티 디스크 ➔ 쓰기 병목(Bottleneck) 발생.
  - `RAID 5`: 모든 멤버 디스크에 패리티 블록 분산 기록 ➔ 쓰기 병목 완벽 해소.
  - `해밍코드`: 단일 비트 오류 정정 및 2비트 오류 검출(SEC-DED) 가능 ➔ 서버 ECC 메모리 및 RAID 2 활용.

- **스토리지 3대 접속 기술 거리·규모·비용 스펙트럼 (2022년 기출 코칭 노트)**:
  - `DAS`: 서버에 전용 케이블(SATA/SAS) 1:1 직결. 가장 짧은 거리, 서버 종속, 최저 비용.
  - `NAS`: 일반 LAN 이더넷망을 통한 **파일 레벨(File-level, NFS/CIFS)** 공유. 중간 거리, 파일 공유 용이, 중간 비용.
  - `SAN`: 광섬유(FC) 전용 스위치 기반 초고속 **블록 레벨(Block-level)** 전송. 원거리/대규모 데이터센터, 최고 성능, 최고 비용.
- **스토리지 RAID 10 성능공학 IOPS 산정 공식 (2022년 기출 코칭 노트)**:
  - $\mathbf{전체\ 읽기\ IOPS} = N 	imes 	ext{디스크당 IOPS}$ (모든 디스크 동시 분산 병렬 읽기).
  - $\mathbf{전체\ 쓰기\ IOPS} = rac{N 	imes 	ext{디스크당 IOPS}}{	ext{쓰기 페널티}(2)}$ (미러링 복제 쓰기로 인해 쓰기 페널티 = 2).
  - **직관적 쓰기 절반의 법칙**: RAID 10은 미러링 특성상 디스크 개수와 무관하게 **쓰기 성능은 항상 읽기 성능의 정확히 절반($1/2$)**임 ($800,000 ightarrow 400,000$).
- **4비트 2의 보수 음수 가중치 직관 계산법 (2022년 기출 코칭 노트)**:
  - 4비트 2진수 $b_3 b_2 b_1 b_0$에서 최상위 비트(MSB) $b_3$은 **$-8$**의 가중치, 나머지 비트는 $+4, +2, +1$의 양수 가중치.
  - 예: $1011 = -8 + 2 + 1 = -5$, $1101 = -8 + 4 + 1 = -3$.
  - $1011(-5) + 1101(-3) = 11000$ ➔ 4비트 결과 $1000(-8)$, 최상위 캐리는 발생하나 오버플로우는 없음.
- **디지털 논리 게이트 패밀리 및 XAND의 부재 이유 (2022년 기출 코칭 노트)**:
  - `N 가문 (NOT 반대)`: $	ext{AND} \leftrightarrow 	ext{NAND}$, $	ext{OR} \leftrightarrow 	ext{NOR}$, $	ext{XOR} \leftrightarrow 	ext{XNOR}$.
  - `XOR (배타적 OR)`: 포괄적 OR(둘 다 1이어도 1)과 달리 둘 다 1인 것을 배제(Exclude)하여 서로 다를 때만 1.
  - `왜 XAND는 없는가`: AND는 원래 '둘 다'만을 뜻하므로 배타성을 붙이면 형용모순임. 비트가 같을 때 1이 나오는 연산은 이미 **`XNOR` (일치/동치 게이트)**가 완벽히 담당함.
- **폰 노이만 구조 vs 하버드 구조 및 현대 CPU 혼합 캐시 (2022년 기출)**:
  - `폰 노이만`: 단일 버스/메모리 공유로 인한 폰 노이만 병목현상 발생.
  - `하버드`: 명령어 버스/메모리와 데이터 버스/메모리 물리적 분리로 병렬 접근 가능.
  - `현대 CPU`: 외부는 단일 메인메모리(폰 노이만), 내부 L1 캐시는 L1 I-Cache와 L1 D-Cache로 분리(하버드) 혼합.
- **캐시 사상 3대 방식 & 쓰기 정책 및 더티 비트 (2022년 기출)**:
  - `사상 3대 방식`: 직접 사상(특정 라인 고정), 완전 연관(어느 위치나 가능, 적중률 최고, 회로비용 최고), 세트 연관(절충).
  - `쓰기 정책`: 쓰기 직통(Write-Through, 캐시-메모리 동시 기록, 더티비트 불필요) vs 쓰기 복귀(Write-Back, 캐시에만 쓰고 교체 시 메모리 기록, **더티 비트 필수**).
- **CPU 파이프라인 3대 해저드 (2022년 기출)**:
  - 구조적(자원 충돌), 데이터(RAW 등 의존성), 제어(분기/점프).
  - 분기 예측과 지연 분기로 완화할 뿐 "100% 완전 제거"는 불가능.
- **아파치 스파크(Spark)와 하둡 2.0 YARN (2022년 기출)**:
  - Spark는 RDD 기반 인-메모리 분산 연산으로 기존 MapReduce 대비 수십~수백 배 고속.
  - 하둡 1.0(HDFS와 MapReduce 결합)과 달리, 하둡 2.0에서 리소스 매니저 **YARN**이 도입되어 HDFS 위에서 Spark 등 이종 분산 엔진이 자유롭게 구동 가능.

### 핵심 포인트 요약
- **인공신경망 딥러닝 핵심 메커니즘 (2025년 기출)**:
  - `순전파 (Forward)`: 입력 데이터에 가중치를 곱해가며 예측값 도출.
  - `손실함수 (Loss Function)`: 실제 정답과 예측값의 오차 및 그 심각도를 측정하는 저울 (MSE, Cross-Entropy).
  - `역전파 (Backpropagation)`: 오차의 미분값(기울기)을 들고 뒤에서부터 [출력층 ➔ 은닉층 ➔ 입력층] 순서로 거슬러 올라가며 가중치를 수정·갱신하는 알고리즘 (연쇄법칙, Chain Rule).
  - `경사 소실 (Gradient Vanishing)`: 역전파 시 기울기가 계속 곱해져 입력층 쪽으로 갈수록 0으로 수렴해 앞쪽 층이 학습되지 않는 현상. **은닉층을 증가시키면 경사소실이 극심하게 악화됨!** (해결책: ReLU 함수 사용, He 가중치 초기화, 배치 정규화, ResNet 잔차 연결).
  - `과적합 (Overfitting)`: 기출문제만 달달 외워 시험장 실전 시험에서 점수가 무너지는 학생과 동일 (학습 데이터 과도 암기, 일반화 실패).
  - `정규화 (Regularization, 가중치 규제)`: 손실함수에 가중치 크기 페널티(벌금)를 부여하여 가중치가 비정상적으로 커지는 것을 억제함으로써 모델을 단순하고 부드러운 형태로 만들어 과적합을 방지.
    - `L1 라쏘(Lasso)`: 가중치 절댓값 합($\sum |w|$) 페널티 ➔ 중요하지 않은 가중치를 진짜 0으로 만듦 (변수 선택 효과).
    - `L2 릿지(Ridge)`: 가중치 제곱의 합($\sum w^2$) 페널티 ➔ 가중치들을 골고루 0에 가깝게 작게 눌러줌.
- **머신러닝 학습 패러다임 분류 (2025년 기출)**:
  - `비지도 학습 (Unsupervised)`: 정답 레이블(Target) 없이 데이터 유사도/거리 기반으로 패턴 발견 (**K-평균 군집화**, 계층 군집, PCA 차원축소, DBSCAN).
  - `지도 학습 (Supervised)`: 정답 레이블을 제공하여 학습 (분류: 나이브 베이즈, SVM, 의사결정나무 / 회귀: 선형 회귀).
- **양자 컴퓨팅 (Quantum Computing) 핵심 특성 및 한계 (2025년 기출)**:
  - `큐비트 (Qubit)`: 0과 1이 동시에 존재하는 중첩(Superposition)으로 대규모 다수 입력 동시 병렬 처리. 관측(측정) 시 0 또는 1로 상태 붕괴.
  - `디코히어런스 (Decoherence, 결어긋남)`: 극미세 온도 변화(열), 전자기파 노이즈, 진동 등 환경 간섭에 극도로 취약하여 양자 상태가 깨짐.
  - `치명적 난제와 오류`: **전송 및 연산 중 오류가 매우 빈번하게 발생**하며, 복제 불가능 정리로 인해 **양자 오류 정정(QEC: Quantum Error Correction)** 기술이 양자 컴퓨터 상용화의 핵심 전제조건임. ("오류가 발생하지 않는다"는 완전한 거짓).
  - `쇼어(Shor) 알고리즘`: 소인수분해 주기를 찾아 RSA 공개키 암호 체계를 다항 시간 내에 해독.
- **자연어 처리(NLP) 및 LLM 4단계 파이프라인 (2025년 기출)**:
  - 1단계 `토큰화 (Tokenization)`: 문장을 최소 의미 단위 블록(토큰)으로 분할 (BPE 등).
  - 2단계 `임베딩 (Embedding)`: 단어를 의미적 유사도가 반영된 고차원 실수 벡터(숫자 좌표) 공간으로 매핑.
  - 3단계 `어텐션 (Attention)`: 문장 내 단어 간 맥락적 연관도와 주목 가중치 계산 (트랜스포머 심장).
  - 4단계 `파인튜닝 (Fine-tuning)`: 사전학습된 거대 모델에 특정 전문 도메인(법률, 의료, 감리 등) 데이터를 추가 학습시켜 파라미터 미세 조정.
- **파인튜닝(Fine-tuning) vs RAG(검색 증강 생성) 핵심 비교**:
  - `파인튜닝 (클로즈드북 암기 시험)`: 모델 가중치를 직접 변경/재학습. 말투, 서식, 행동 양식 개조에 적합. 최신 데이터 갱신 시 재학습 비용 발생, 환각 위험 여전.
  - `RAG (오픈북 시험)`: 모델 가중치는 동결(그대로 유지), 질문 시 외부 사내 문서 DB에서 실시간 검색(Retrieval)하여 프롬프트에 결합·생성(Generation). **최신 규정/문서 즉시 반영, 명확한 출처 표기, 환각(거짓말) 원천 차단**으로 기업 구축 1순위 표준.
- **NIA 초거대 AI 데이터 품질관리 지표 (2025년 기출)**:
  - `구축공정`: 준비성(Readiness - 적합성/윤리), 완전성(Completeness - 누락 방지), 유용성(Usability - 가공 적정성).
  - `활용공정`: **유효성(Effectiveness)** - 실제 모델 입력 시의 성능, 답변 정확도, 환각 억제율.

- **AI $\supset$ 머신러닝 $\supset$ 딥러닝 포함 관계 및 분류 (2024년 기출)**:
  - : 순수 통계/기하학/최적화 기법. **특징(Feature)을 사람이 직접 추출**.
    - 대표: **SVM (서포트 벡터 머신, 최대 마진 초평면)** *(단골 오답!)*, 의사결정나무, 랜덤포레스트, KNN, 나이브베이즈.
  - : 인간 뇌 뉴런을 모방한 깊은 은닉층. **특징을 신경망이 스스로 학습/추출**.
    - 대표: CNN, RNN, 트랜스포머, DBN, VAE, GAN.
- **트랜스포머 3대 파생 아키텍처 계보 (2024년 기출)**:
  - 1. : 문맥 이해, 문서 분류, 검색 랭킹, RAG 임베딩 특화.
    - 대표 모델: **BERT**, RoBERTa, ALBERT, SBERT. (디코더 없음, 생성 불가)
  - 2. : 다음 토큰 예측 문장 생성, 대화 챗봇, 현대 LLM 주류.
    - 대표 모델: **GPT-4**, LLaMA, Gemini, Claude, Mistral.
  - 3. : 입력 이해 후 새 문장 출력, 번역/요약 특화.
    - 대표 모델: **원조 Transformer**, T5, BART.

- **머신러닝 k-NN (k-Nearest Neighbor) 알고리즘 (2023년 기출)**:
  - **지도학습 (Supervised Learning)** 기반 분류(Classification) 및 회귀 알고리즘.
  - **Lazy Learner (게으른 학습자)**: 사전 훈련 모델을 구축하지 않고, 질의 시점에 주변 $k$개 이웃 데이터의 거리를 계산하여 다수결(Majority Voting)로 결과 도출.
  - *(※ K-Means는 비지도 군집화, k-NN은 지도학습 분류)*
- **신경망 vs 비신경망 모델 분류 (2023년 94번 ➔ 2024년 96번 100% 동일 복제 재출제)**:
  - `인공신경망 딥러닝`: GAN(생성적 적대 신경망), DBN(심층 신뢰 신경망), VAE(변이형 오토인코더), MLP, CNN, RNN.
  - `비신경망 통계/기하학 모델`: **SVM (Support Vector Machine, 서포트 벡터 머신)** ➔ 데이터 간 최대 마진(Margin)을 갖는 결정 초평면을 기하학적으로 산출.
- **딥러닝 2대 부품: 활성화 함수 vs 최적화 함수 (2023년 기출)**:
  - `활성화 함수 (Activation Function)`: 선형 연산 결과를 비선형으로 변환. **ReLU (Rectified Linear Unit, $f(x)=\max(0, x)$)** ➔ 양수 구간에서 미분값이 1로 유지되어 시그모이드의 **기울기 소실(Vanishing Gradient) 문제를 극복**.
  - `최적화 함수 (Optimizer)`: 손실 함수를 최소화하도록 가중치를 갱신하는 알고리즘 (SGD, RMSProp, Adam).
- **트랜스포머 아키텍처: GPT vs BERT (2023년 기출)**:
  - `GPT (Generative Pre-trained Transformer)`: 디코더(Decoder) 전용 구조, 단방향(Causal Masking), 생성형 문장 작성 특화.
  - `BERT (Bidirectional Encoder Representations from Transformers)`: 인코더(Encoder) 전용 구조, 양방향(Masked LM), 문맥 이해 및 문서 분류 특화.
- **전이 학습 (Transfer Learning) (2023년 기출)**:
  - 대규모 데이터셋으로 이미 사전 훈련된(Pre-trained) 신경망의 가중치와 지식을 유사한 신규 도메인/태스크에 이전하여 재사용하는 기법 (Fine-tuning 연계).
