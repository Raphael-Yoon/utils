### 핵심 포인트 요약
- **SDN (Software Defined Networking) 3개 평면과 2개 인터페이스 (2025년 기출)**:
  - `구조적 3개 평면`:
    - `Application Plane`: 최상위 네트워크 모니터링, 보안, QoS 관리 응용 프로그램 (SW).
    - `Control Plane`: 중앙 집중형 SDN 컨트롤러. 망 전체의 최적 경로 계산 및 정책 수립 (SW, x86 리눅스 서버 등에서 독립 구동).
    - `Data Plane`: 패킷을 실제로 포워딩(전송)하는 물리 스위치/라우터 하드웨어 (HW).
  - `2대 핵심 인터페이스`:
    - `Northbound Interface`: Application Plane ↔ Control Plane (RESTful API / JSON 활용).
    - `Southbound Interface`: Control Plane ↔ Data Plane (공식 명칭: **Control Data Plane Interface, CDPI** / 표준 통신 프로토콜: **OpenFlow**).
  - `트래픽 흐름 원칙`: **실제 사용자 데이터 패킷(유튜브, 웹 트래픽)은 컨트롤러로 올라가지 않고 Data Plane 스위치들끼리 초고속 하드웨어 링크로 직접 전달됨!** Southbound는 오직 제어 규칙(Flow Table)과 모니터링 신호만 오고 감.
- **차분 맨체스터(Differential Manchester) 파형 판독 공식 (2025년 기출)**:
  - 비트 주기 한가운데(Center)의 전이는 클록 동기화용이므로 무시하고, **비트와 비트 사이의 '경계선(Boundary)' 전이 유무**만 관찰.
  - 비트 경계선에 **신호 전이(수직선) 발생** ➔ **`0`**
  - 비트 경계선에 **신호 전이 없음 (수평 평탄선 유지)** ➔ **`1`**
- **VLAN 프레임 태깅 표준 IEEE 802.1Q ('닷원큐') (2025년 기출)**:
  - 복수 스위치 간 트렁크(Trunk) 링크에서 이더넷 프레임의 MAC과 Type 사이에 **4바이트(32비트) 크기의 VLAN 태그** 삽입 (TPID 2B + TCI 2B, 12비트 VID로 최대 4,094개 VLAN 지원). 8바이트 왜곡 주의.
- **통신 QoS 4대 핵심 지표 (2025년 기출)**:
  - `지터(Jitter)`: 패킷 교환망에서 네트워크 혼잡 등으로 인해 발생하는 **'패킷 간 지연 시간의 불규칙한 변이/편차'**. 실시간 음성(VoIP) 및 스트리밍 품질의 결정적 지표.
  - `지연(Latency)`, `패킷 손실(Packet Loss)`, `처리율(Throughput)`.
- **전자우편 프로토콜 명령어 (POP3 vs SMTP) (2025년 기출)**:
  - `POP3 (수신, 포트 110)`: `LIST` (목록 조회), `RETR` (메일 가져오기), `DELE` (삭제), `STAT` (통계).
  - `SMTP (발송, 포트 25)`: `HELO/EHLO`, `MAIL FROM`, `RCPT TO`, `DATA`.
- **전파 신호 파장 계산 공식 (2025년 기출)**:
  - $\lambda = \frac{v}{f}$ (전파 속도 $v = 3 \times 10^8$ m/s, $f = 3$ kHz = $3 \times 10^3$ Hz ➔ $\lambda = 100,000$ m).
- **오류 제어 vs 데이터 부호화 (2025년 기출)**:
  - 패리티(Parity), 블록합(LRC/Checksum), CRC는 전송 오류 검출 기법.
  - BCD(Binary Coded Decimal)는 10진수 숫자를 4비트 2진수로 표현하는 데이터 부호화 방식 (오류 검출 아님).
- **TCP 혼잡 제어 4단계**:
  - `Slow Start`: 개별 ACK마다 cwnd +1 (RTT마다 2배 지수 증가).
  - `Congestion Avoidance`: 임계값 도달 후 RTT당 1씩 선형 증가.
  - `Fast Retransmit`: 3 중복 ACK 감지 시 단 1개의 손실 패킷 즉시 재전송.
  - `Fast Recovery`: cwnd를 절반 지점(ssthresh)부터 1씩 완만하게 증가.
- **IPv4 vs IPv6 헤더 구조 비교**:
  - `기본 헤더`: IPv4는 가변(20~60B), IPv6는 **40바이트 고정**.
  - `IPv6 변경 사항`: **Header Checksum 삭제**, **IHL 삭제**, IPv4 `TTL` ➔ IPv6 **`Hop Limit`**으로 공식 개명.

### 핵심 포인트 요약
- **시스템 진단 및 백도어 탐지 명령어 `netstat` (2025년 기출)**:
  - 어원: **Net**work **Stat**istics (네트워크 종합 통계 및 상태).
  - 핵심 옵션 해체:
    - `-a` (All): 연결된 세션뿐만 아니라 **대기(Listening) 중인 모든 포트** 출력 (백도어 대기 포트 탐지 필수).
    - `-n` (Numeric): 도메인/서비스명 역방향 조회 없이 **숫자 IP 및 포트 번호**로 직관적·고속 표시.
    - ➔ **`netstat -an`**: 침해사고 시 백도어 오픈 포트 및 외부 C&C 서버 연결 상태를 확인하는 표준 명령어.
    - `-r` (Routing): 라우팅 테이블 출력.
    - `-s` (Statistics): IP/TCP/UDP 프로토콜별 누적 통계 패킷 수 요약.
    - `-p`: Linux에서는 프로세스(PID/프로그램명), Windows에서는 프로토콜(TCP/UDP 필터링). *(Windows PID 확인은 `-ano`)*.
- **CPU 스케줄링 다단계 피드백 큐 (MLFQ) (2025년 기출)**:
  - 다단계 큐(MLQ)는 큐 간 프로세스 이동이 불가하여 하위 큐의 기아(Starvation) 발생.
  - 다단계 피드백 큐(MLFQ)는 **큐 간 동적 이동(피드백)을 완벽 허용** (CPU 집중 프로세스는 하위 큐 강등, 대기 시간 긴 프로세스는 에이징(Aging)을 통해 상위 큐로 승격하여 기아 방지).
- **가상 메모리 페이지 교체 알고리즘 (LRU vs LFU) (2025년 기출)**:
  - `LRU (Least Recently Used)`: **가장 오랫동안 사용되지 않은 시간(시간적 경과)**을 기준으로 교체.
  - `LFU (Least Frequently Used)`: 과거에 참조된 **횟수(빈도, Frequency)**가 가장 적은 페이지를 교체.
- **가상 머신(VM) vs 컨테이너(Docker) 완벽 비교**:
  - `가상 머신 (VM)`: 하이퍼바이저 필수, 게스트 OS(커널) 독립 탑재, 수십 GB 무거움, 완벽한 격리.
  - `컨테이너 (Docker)`: 호스트 OS 커널 공유, 하이퍼바이저 불필요, 초경량 초고속.

### 핵심 포인트 요약
- **TTA 하드웨어 규모산정 지침 연계부하 보정비율 (2025년 기출)**:
  - `WEB 서버`: 연계부하 보정 = **0%** (연계 트래픽 직접 처리 안 함).
  - `WAS 서버 (단순 조회)`: 연계부하 보정 = **10%**.
  - `WAS 서버 (복합/갱신)`: 연계부하 보정 = **30%**.
- **성능공학 복합 업무 최대 TPS 산정 공식 (2025년 기출)**:
  - 복합 트랜잭션 1건의 가중평균 서비스시간 $ST = \sum (\text{업무별 비중} \times \text{처리시간})$.
  - $\text{최대 } TPS = \frac{\text{동시 처리 용량(동시 사용자/쓰레드 수)}}{ST}$.
- **스토리지 RAID 1+0 (RAID 10) 아키텍처 (2025년 기출)**:
  - 드라이브들을 먼저 2개씩 1:1 미러링(RAID 1)한 후, 그 세트들을 데이터 스트라이핑(RAID 0)으로 결합.
  - **패리티(Parity) 연산은 일절 사용하지 않음** (패리티는 RAID 3, 4, 5, 6 전유물).
  - 미러링 세트 내 1개 디스크 장애 시에도 무중단 서비스 지원.
- **디지털 논리회로 카르노맵(K-Map) 간소화 (2025년 기출)**:
  - 진리표에서 출력이 1인 최소항들을 $2^n$ 단위(2개, 4개, 8개)로 인접 칸끼리 최대한 크게 묶어 변수를 소거 ($F = A' + BC$).
- **플린(Flynn)의 컴퓨터 분류 체계 (2025년 기출)**:
  - `SIMD (Single Instruction Multiple Data)`: 단일 제어장치 명령으로 다수의 연산장치(ALU)가 대규모 벡터/배열 데이터를 병렬 연산 (현대 GPU 및 벡터 프로세서 핵심 구조).
- **캐시 메모리 평균 접근 시간 (AMAT) 공식 (2025년 기출)**:
  - $AMAT = \text{L1 접근시간} + (\text{L1 미스율} \times \text{L1 미스 패널티})$.
- **CRC LFSR(선형 피드백 시프트 레지스터) 회로도 판독 (2025년 기출)**:
  - 플립플롭 레지스터 단수 $N$개 ➔ 최고차항 $x^N$.
  - 데이터 유입 입력단 ➔ 상수항 $+1$.
  - 중간 피드백 경로의 XOR 게이트 위치 ➔ 해당 차수 $+x^k$ (예: 4단 레지스터 + 2단 뒤 XOR ➔ $x^4 + x^2 + 1$).
- **멀티미디어 데이터 압축 원리 (2025년 기출)**:
  - 데이터 내부의 반복 패턴 및 중복성(Redundancy)이 많을수록 불필요한 데이터를 제거할 여지가 크므로 **압축률이 높아짐**.
- **부동소수점 나눗셈 연산 (IEEE 754) (2025년 기출)**:
  - 가수는 나눗셈, **지수는 뺄셈** 수행. **지수 덧셈은 오직 곱셈의 전유물**이므로 나눗셈에는 불필요.

## 4. 인공지능 / 머신러닝 / 딥러닝 / 양자컴퓨팅 (신기술)

### 5개년 출제 현황
| 연도 | 2022 | 2023 | 2024 | 2025 | 2026 | 합계 | 출제 개년수 | 빈출도 |
|---|---|---|---|---|---|---|---|---|
| 문항수 | 0 | 0 | 1 | 4 | 2 | 7 | 4/5 | ★★★★★ |

### 핵심 포인트 요약
- **인공신경망 딥러닝 핵심 메커니즘 (2025년 기출)**:
  - `순전파 (Forward)`: 입력 데이터에 가중치를 곱해가며 예측값 도출.
  - `손실함수 (Loss Function)`: 실제 정답과 예측값의 오차 및 그 심각도를 측정하는 저울 (MSE, Cross-Entropy).
  - `역전파 (Backpropagation)`: 오차의 미분값(기울기)을 들고 뒤에서부터 [출력층 ➔ 은닉층 ➔ 입력층] 순서로 거슬러 올라가며 가중치를 수정·갱신하는 알고리즘 (연쇄법칙, Chain Rule).
  - `경사 소실 (Gradient Vanishing)`: 역전파 시 기울기가 계속 곱해져 입력층 쪽으로 갈수록 0으로 수렴해 앞쪽 층이 학습되지 않는 현상. **은닉층을 증가시키면 경사소실이 극심하게 악화됨!** (해결책: ReLU 함수 사용, He 가중치 초기화, 배치 정규화, ResNet 잔차 연결).
  - `과적합 (Overfitting)`: 기출문제만 달달 외워 시험장 실전 시험에서 점수가 무너지는 학생과 동일 (학습 데이터 과도 암기, 일반화 실패).
  - `정규화 (Regularization, 가중치 규제)`: 손실함수에 가중치 크기 페널티(벌금)를 부여하여 가중치가 비정상적으로 커지는 것을 억제함으로써 모델을 단순하고 부드러운 형태로 만들어 과적합을 방지.
    - `L1 라쏘(Lasso)`: 가중치 절댓값 합($\sum |w|$) 페널티 ➔ 중요하지 않은 가중치를 진짜 0으로 만듦 (변수 선택 효과).
    - `L2 릿지(Ridge)`: 가중치 제곱의 합($\sum w^2$) 페널티 ➔ 가중치들을 골고루 0에 가깝게 작게 눌러줌.
- **머신러닝 학습 패러다임 분류 (2025년 기출)**:
  - `비지도 학습 (Unsupervised)`: 정답 레이블(Target) 없이 데이터 유사도/거리 기반으로 패턴 발견 (**K-평균 군집화**, 계층 군집, PCA 차원축소, DBSCAN).
  - `지도 학습 (Supervised)`: 정답 레이블을 제공하여 학습 (분류: 나이브 베이즈, SVM, 의사결정나무 / 회귀: 선형 회귀).
- **양자 컴퓨팅 (Quantum Computing) 핵심 특성 및 한계 (2025년 기출)**:
  - `큐비트 (Qubit)`: 0과 1이 동시에 존재하는 중첩(Superposition)으로 대규모 다수 입력 동시 병렬 처리. 관측(측정) 시 0 또는 1로 상태 붕괴.
  - `디코히어런스 (Decoherence, 결어긋남)`: 극미세 온도 변화(열), 전자기파 노이즈, 진동 등 환경 간섭에 극도로 취약하여 양자 상태가 깨짐.
  - `치명적 난제와 오류`: **전송 및 연산 중 오류가 매우 빈번하게 발생**하며, 복제 불가능 정리로 인해 **양자 오류 정정(QEC: Quantum Error Correction)** 기술이 양자 컴퓨터 상용화의 핵심 전제조건임. ("오류가 발생하지 않는다"는 완전한 거짓).
  - `쇼어(Shor) 알고리즘`: 소인수분해 주기를 찾아 RSA 공개키 암호 체계를 다항 시간 내에 해독.
- **자연어 처리(NLP) 및 LLM 4단계 파이프라인 (2025년 기출)**:
  - 1단계 `토큰화 (Tokenization)`: 문장을 최소 의미 단위 블록(토큰)으로 분할 (BPE 등).
  - 2단계 `임베딩 (Embedding)`: 단어를 의미적 유사도가 반영된 고차원 실수 벡터(숫자 좌표) 공간으로 매핑.
  - 3단계 `어텐션 (Attention)`: 문장 내 단어 간 맥락적 연관도와 주목 가중치 계산 (트랜스포머 심장).
  - 4단계 `파인튜닝 (Fine-tuning)`: 사전학습된 거대 모델에 특정 전문 도메인(법률, 의료, 감리 등) 데이터를 추가 학습시켜 파라미터 미세 조정.
- **파인튜닝(Fine-tuning) vs RAG(검색 증강 생성) 핵심 비교**:
  - `파인튜닝 (클로즈드북 암기 시험)`: 모델 가중치를 직접 변경/재학습. 말투, 서식, 행동 양식 개조에 적합. 최신 데이터 갱신 시 재학습 비용 발생, 환각 위험 여전.
  - `RAG (오픈북 시험)`: 모델 가중치는 동결(그대로 유지), 질문 시 외부 사내 문서 DB에서 실시간 검색(Retrieval)하여 프롬프트에 결합·생성(Generation). **최신 규정/문서 즉시 반영, 명확한 출처 표기, 환각(거짓말) 원천 차단**으로 기업 구축 1순위 표준.
- **NIA 초거대 AI 데이터 품질관리 지표 (2025년 기출)**:
  - `구축공정`: 준비성(Readiness - 적합성/윤리), 완전성(Completeness - 누락 방지), 유용성(Usability - 가공 적정성).
  - `활용공정`: **유효성(Effectiveness)** - 실제 모델 입력 시의 성능, 답변 정확도, 환각 억제율.
