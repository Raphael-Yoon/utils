# 광진랜드 시뮬레이션 시스템 (Casino Simulator)

이 프로젝트는 도박의 수학적 설계와 통계적 필패 구조를 시각화하는 카지노 시뮬레이터입니다.

## 포함된 게임
1. **바카라 (Baccarat)**: 뱅커 수수료(5%)가 승률에 미치는 영향을 증명.
2. **룰렛 (Roulette)**: '0(Zero)'이라는 하우스 엣지가 확률의 균형을 무너뜨리는 원리 공유.
3. **블랙잭 (Blackjack)**: 플레이어가 먼저 카드를 받아 파산하는 구조적 불리함 확인.
4. **슬롯머신 (Slots)**: 94%의 RTP가 자산을 어떻게 잠식하는지 시뮬레이션.
5. **식보 (Sic Bo)**: 트리플(Triple)이라는 예외 법칙이 플레이어의 기대를 꺾는 과정 확인.
6. **빅휠 (Big Wheel)**: 화려한 외관 뒤에 숨겨진 압도적인 하우스 엣지(최대 24%) 체험.

## 주요 기능
- **고속 AI 시뮬레이션**: 최대 10배속 시뮬레이션 지원.
- **베팅하기 (Run Once)**: 단일 라운드를 수동으로 진행하며 결과를 면밀히 분석 가능.
- **실시간 데이터 분석 (Math Analysis)**: 승률 수렴 바, 최장 연승/연패 기록, ROI 및 하우스 엣지 추적.
- **자산 변동 차트**: 라운드별 자산 흐름을 선 그래프로 시각화.
- **절대 안정 레이아웃**: 어떤 화면 크기나 속도에서도 무너지지 않는 Grid 기반 UI.
